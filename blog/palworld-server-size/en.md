## Palworld wants RAM, and that is not an exaggeration

A Palworld server is very different from a Minecraft one. Minecraft runs comfortably on 3 GB; Palworld does not work that way.

And the reason is not player count alone — the world itself is heavy: every character, every pal and every built base stays held in memory for as long as the server is up.

## Pocketpair's own numbers

The developer states it plainly:

- **8 GB is the minimum** — and plenty of servers at that floor crash on their own.
- **16 GB or more** is what they recommend for a stable server.
- **32 GB** for a full 32-player server.

Take that seriously. Most "my Palworld server keeps crashing" complaints trace back to a server running at the minimum.

> [!warning] Do not start at 8 GB if you intend to play seriously. That is the "it runs" number, not the "it runs steadily" number.

## Why does RAM grow over time?

This is the part that surprises people: a Palworld server starts light and gets heavier.

The more bases you build, the more pals you collect and the further you explore, the more the server has to keep in memory. A server in its first week is not the same server in its third month, even with the same players.

So when you pick a plan, do not size it for day one — size it for where you will be two months in.

## The standard fix: a nightly restart

The approach everyone running a serious Palworld server uses: a scheduled restart every day, usually at an hour when nobody is online.

The restart clears the accumulated memory and returns the server to its normal state, so it never slows down on you or crashes out of nowhere.

On Serverk you schedule it from the schedules tab in your server panel, and it runs itself every day without you opening anything.

## How many players on how much RAM?

Tie it back to the numbers above:

- **A small group, 4 to 8 players, a handful of bases** — 16 GB is comfortable.
- **A full 32-player server** — 32 GB is what the developer recommends.
- **Below 16 GB** — it may run, but expect crashes now and then as your world grows.
