## Overview

The first tab you land on: live server state, CPU, RAM and disk usage, players online, and the start, stop and restart buttons. Your server address sits at the top — one button copies it.

## Console

The live server log, exactly as the server prints it. Below the log sits a command box — type any command your game server supports and see the result instantly.

> [!note] The console is the fastest way to diagnose anything: if your server keeps restarting or refuses connections, the real error message lives here.

## Files

A full file manager in the browser: browse, edit, upload, download and rename. Text and config files open in a built-in editor with syntax highlighting.

> [!warning] Edit game files only when you know what you are doing — the important settings have safe fields in the settings tab, so you rarely need to touch files directly.

## Settings

Your game's settings as clear fields, no files involved: every field carries its own explanation, and values are written into the game files in the correct format. Version changes happen here too, and at the bottom sits the **danger zone** — reinstall and delete.

## Your game's tabs

Some games add their own tabs: plugins and mods for one-click installs, and **Guides** — the game's own guides right inside the panel, so you never have to leave it.
