A tour of your server panel's areas and what each one is for. Every tab is in the side menu.

![The panel's side menu with numbers on the Overview, Console, Files and Settings tabs.](guides/panel-basics/panel-tabs.webp)

## Overview

The first tab you land on: live server state, and CPU, RAM and disk usage. Your server address is at the top, and one button copies it. The players online are in the **Players** tab.

![The Overview tab with the server state, its address and resource use, and the top bar marked.](guides/panel-basics/overview.webp "The start, restart and stop buttons are in the top bar of every tab.")

## Console

The live server log, exactly as the server prints it, colors included. Below the log is a command box: type any command your game server supports, and its output shows in the log.

![The console with the server log and the command box at the bottom marked.](guides/panel-basics/console-command.webp)

> [!note] The console is the fastest way to diagnose anything: if your server keeps restarting or refuses connections, the real error message is here.

## Files

A full file manager in the browser: browse, edit, upload, download and rename. Text and config files open in a built-in editor with syntax highlighting.

![The Files tab with the server's folders and the upload button marked.](guides/panel-basics/files.webp)

> [!warning] Edit game files only when you know what you're doing. The important settings have safe fields in the Settings tab, so you rarely need to touch files directly.

## Settings

Your game's settings as clear fields, no files involved: every field carries its own explanation, and values are written into the game files in the correct format. Games that let you change the version give it its own tab, such as **Version** in Minecraft Java. The reset and canceling the server are in the **Manage** tab, under **Danger zone**.

![The Settings tab with the game's settings in sections of fields, the first section marked.](guides/panel-basics/settings.webp)

## Your game's tabs

Some games add their own tabs under the game's name in the menu, such as plugins and mods for one-click installs. The **Guides** button in the top bar opens your game's guides right inside the panel, so you never have to leave it.
